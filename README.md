# 纳指100历史长卷

交互式价格历史图表，含重大事件、回撤与恢复天数，以及《拉德茨基进行曲》配乐。

## 开启网页访问

仓库 Settings → Pages → Deploy from a branch → main → /(root) → Save。等待GitHub显示实际网站地址后再分享。

## 数据与使用口径

日线来自FRED转载的Nasdaq价格指数，1986-01-02至2026-11-19。1985日线未取得，只有成立基点，不连线补造。2026-11-20的25028.98点为补充行情，待FRED原序列复核。事件仅为同期背景，不代表唯一原因。页面内含各项来源与计算口径。历史回报不代表未来收益。

## 配乐

见「配乐来源与许可.md」。作品及演奏录音的来源页面标注为公有领域。音频拆分成资源文件以适配上传，浏览器按原顺序自动恢复，音频内容没有剪辑。

## 发布版本

2026-11-21快照。事件固定停留1.5秒，卷轴展开后淡出，无秒数提示。音乐始终原速，动画倍速不改变音乐。
